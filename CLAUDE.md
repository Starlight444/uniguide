# UniGuide - AI Coding Instructions

## Project Overview
UniGuide is a web application that helps university
students find information from university documents.

## Tech Stack
- Frontend: React + Vite
- Language: JavaScript
- Backend: Python + FastAPI (planned)

## Commands
- `npm run dev` — start the dev server
- `npm run build` — production build
- `npm run lint` — run ESLint

## Coding Rules
- Use functional React components and hooks.
- Keep components small and reusable.
- Separate UI components from API logic.
- Use clear and descriptive variable names.
- Follow the existing project structure.
- Do not install new packages without explaining why.
- Do not rewrite unrelated files when fixing a bug.

## Working Instructions
- Explain changes in beginner-friendly language.
- When adding a feature, list the files that will change.
- Keep existing features working.
- If requirements are unclear, ask before making
  major changes.
- Do not claim a feature works without testing it.

## Security
- Never expose API keys in frontend code.
- Store secrets in environment variables.
- Never commit .env files containing secrets.
